# 사람인 채용공고 추출기

사람인 채용공고 상세 페이지를 읽어 `채용공고 분석 DB` 속성에 맞는 JSON으로 정리하는 Chrome 확장 프로그램입니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더(`saramin-notion-extractor`)를 선택합니다.

## 사용

1. 사람인 채용공고 상세 페이지를 엽니다.
2. 툴바의 확장 프로그램 아이콘을 누릅니다.
3. **페이지 스캔**을 누릅니다.
4. 미리보기를 확인한 뒤 JSON을 복사하거나 저장합니다.
5. 이미지형 공고로 감지되면 **이미지 OCR로 읽기**를 누르고 진행률이 100%가 될 때까지 팝업을 열어 둡니다.

## 현재 범위

- 기준 공고: 일반 상세 `rec_idx=54090584`, 이어보기 `rec_idx=54632103`
- `/jobs/relay/view`에서도 URL의 현재 `rec_idx` 공고 하나만 추출합니다.
- 이어보기 화면에 미리 불러온 추천 공고와 상단 고정 제목은 추출 대상에서 제외합니다.
- 텍스트형 상세 공고는 직접 추출합니다.
- 이미지형 공고는 내장된 Tesseract.js 한국어+영어 OCR로 읽습니다.
- OCR은 외부 API로 이미지를 전송하지 않고 현재 컴퓨터에서 처리합니다.
- OCR은 글꼴·해상도·배경에 따라 오인식할 수 있으므로 저장 전 미리보기를 확인해야 합니다.
- OCR 실행 파일과 언어 모델이 포함되어 확장 프로그램 용량이 약 64MB 증가합니다.
- Notion 직접 저장은 다음 단계에서 OAuth 또는 안전한 중계 방식으로 연결할 수 있습니다.
