# v1.0.0 수동 검증 체크리스트

실제 Notion 토큰과 개인 데이터 소스 ID는 기록·화면 녹화·커밋에 포함하지 않는다.

## 새 Chrome 프로필

- [ ] README만 보고 압축해제 확장 프로그램을 설치할 수 있다.
- [ ] 개인 기본 데이터 소스 ID가 미리 채워져 있지 않다.
- [ ] 토큰·데이터 소스 ID 저장 후 연결 테스트가 성공한다.

## 공고 유형

- [ ] 일반 텍스트 상세 공고 1건의 모든 필드를 추출한다.
- [ ] 이어보기 상세 공고 1건에서 현재 `rec_idx`만 추출한다.
- [ ] 이미지형 공고 1건을 OCR하고 미리보기를 교정해 저장한다.
- [ ] 같은 공고를 두 번 실행해 Notion 페이지 수가 늘지 않고 기존 항목이 업데이트된다.

## 일괄수집과 복구

- [ ] 검색 URL 2개 이상을 순차 처리한다.
- [ ] 최근 N일, 페이지 제한, 전체 공고 제한이 각각 적용된다.
- [ ] 실행 중 중지를 누르면 안전 작업 종료 후 30초 안에 `cancelled`가 기록된다.
- [ ] 처리 도중 Chrome을 종료한 뒤 다시 열면 마지막 완료 공고 다음부터 재개한다.
- [ ] 401·403·404는 전체 실행을 중단하고 해결 방법을 표시한다.
- [ ] 개별 파싱·OCR 실패는 기록하고 다음 공고를 처리한다.
- [ ] 실행 이력과 신규·업데이트·중복·실패 합계가 실제 결과와 일치한다.

## 예약과 공개 자료

- [ ] 예약 시각 1분 안에 실행이 시작된다.
- [ ] 예약 시각에 Chrome을 종료했다가 시작하면 같은 주에 보충 실행이 한 번만 시도된다.
- [ ] 토큰·데이터 소스 ID·개인 Notion URL을 가린 상태로 1분 이내 데모를 다시 촬영한다.
- [ ] `npm test`, `npm run check`, GitHub Actions가 모두 통과한다.
