# Notion 토큰 발급 및 연결 가이드

이 확장 프로그램은 개인 워크스페이스용 **내부 연결**을 사용합니다. OAuth 로그인은 사용하지 않습니다. 연결과 토큰은 하나의 Notion 워크스페이스에만 속하므로, 데이터베이스가 있는 워크스페이스를 정확히 선택해야 합니다.

## 준비 사항

- Notion 채용공고 데이터베이스
- 해당 워크스페이스에서 연결을 만들거나 추가할 수 있는 권한
- Chrome에 설치한 사람인 채용공고 추출기

회사 또는 학교 워크스페이스에서 **자체 연결 개발** 메뉴가 보이지 않으면 워크스페이스 소유자에게 연결 생성을 요청하거나 개인 워크스페이스에서 진행합니다.

## 1. 내부 연결 만들기

1. Notion 왼쪽 사이드바에서 **설정**을 엽니다.
2. **연결**을 선택합니다.
3. 화면 아래의 **자체 연결 개발**을 누릅니다.
4. 브라우저에 열린 My connections 화면에서 **+ 새 연결**을 누릅니다.
5. 이름에 `사람인 채용공고 추출기`처럼 알아보기 쉬운 이름을 입력합니다.
6. 채용공고 데이터베이스가 있는 워크스페이스를 선택하고 연결을 만듭니다.

Notion 공식 설명: [Notion API 연결 만들기](https://www.notion.com/help/create-integrations-with-the-notion-api)

## 2. 필요한 권한 설정하기

연결 설정에서 콘텐츠 관련 권한을 다음과 같이 허용합니다.

- 콘텐츠 읽기: 데이터 소스 구조와 기존 공고를 조회할 때 필요
- 콘텐츠 삽입: 새 채용공고 페이지를 만들 때 필요
- 콘텐츠 업데이트: 같은 공고를 다시 수집해 기존 페이지를 갱신할 때 필요
- 사용자 정보: 사용하지 않으므로 허용하지 않아도 됨

권한을 변경했다면 저장합니다. Notion의 권한 설명은 [Connection capabilities](https://developers.notion.com/reference/capabilities)에서 확인할 수 있습니다.

## 3. 설치 액세스 토큰 복사하기

1. Notion **설정 → 연결**로 돌아갑니다.
2. 만든 내부 연결 오른쪽의 **•••**를 누릅니다.
3. **설치 액세스 토큰 복사**를 선택합니다.
4. 복사한 값은 잠시 안전한 곳에만 보관합니다.

토큰은 일반적으로 `ntn_` 또는 기존 형식인 `secret_`로 시작할 수 있습니다. 토큰은 비밀번호와 같으므로 다음 위치에 넣으면 안 됩니다.

- Git 커밋과 GitHub Issues/PR
- README나 샘플 JSON
- 공개 스크린샷과 시연 영상
- 메신저 또는 공용 PC의 메모장

토큰이 노출됐다면 Notion에서 해당 연결의 토큰을 재발급하거나 연결을 삭제한 뒤 새로 만듭니다.

## 4. 채용공고 데이터베이스에 연결 추가하기

새 연결은 생성 직후 어떤 페이지도 읽을 수 없습니다. 데이터베이스 페이지에 접근 권한을 별도로 줘야 합니다.

1. 채용공고 데이터베이스를 Notion에서 전체 페이지로 엽니다.
2. 오른쪽 위 **•••** 메뉴를 누릅니다.
3. **연결 추가**를 선택합니다.
4. 앞에서 만든 연결을 검색해 선택합니다.
5. 확인 창이 표시되면 접근을 허용합니다.

연결 이름이 검색되지 않으면 데이터베이스와 연결이 서로 다른 워크스페이스에 만들어졌는지 확인합니다. 연결의 페이지 접근 방식은 [Notion 연결 관리 도움말](https://www.notion.com/help/add-and-manage-connections-with-the-api)을 참고하세요.

## 5. 데이터 소스 속성 만들기

데이터 소스의 속성 이름과 유형을 아래 표와 정확히 맞춥니다. 이름의 띄어쓰기와 슬래시도 동일해야 합니다.

| 속성 이름 | Notion 유형 |
|---|---|
| 회사/직무(제목) | 제목 |
| 공고링크 | URL |
| 주요업무 | 텍스트 |
| 지원자격 | 텍스트 |
| 우대사항 | 텍스트 |
| 기술스택 | 다중 선택 |
| 자격/어학 | 텍스트 |
| 근무조건/복지 | 텍스트 |
| 지역 | 텍스트 |
| 마감일 | 날짜 |

`공고링크`는 중복 확인 기준이므로 반드시 URL 유형이어야 합니다.

## 6. 데이터 소스 ID 복사하기

Notion API 2025-09-03 이후에는 데이터베이스 컨테이너 ID와 데이터 소스 ID가 구분됩니다. 이 확장 프로그램에는 **데이터 소스 ID**가 필요합니다.

1. 데이터베이스를 전체 페이지로 엽니다.
2. 데이터베이스 설정 메뉴에서 **데이터 소스 관리**를 선택합니다.
3. 사용할 데이터 소스 오른쪽의 **•••**를 누릅니다.
4. **데이터 소스 ID 복사**를 선택합니다.

다음 값과 혼동하지 마세요.

- 데이터베이스 공유 링크에 포함된 데이터베이스 ID
- URL의 `?v=` 뒤에 있는 보기 ID
- 개별 채용공고 페이지 ID

공식 안내: [Working with databases — ID 찾기](https://developers.notion.com/guides/data-apis/working-with-databases)

## 7. 확장 프로그램에 연결하기

1. Chrome 툴바에서 **사람인 채용공고 추출기**를 엽니다.
2. **Notion 연결 설정**을 펼칩니다.
3. **Notion 액세스 토큰**에 설치 액세스 토큰을 붙여 넣습니다.
4. **데이터 소스 ID**에 복사한 데이터 소스 ID를 붙여 넣습니다.
5. **설정 저장**을 누릅니다.
6. **연결 테스트**를 누릅니다.
7. `Notion 연결 성공`과 데이터 소스 이름이 표시되는지 확인합니다.

연결에 성공하면 사람인 상세 공고 한 건을 스캔하고 **Notion에 저장**을 눌러 실제 저장을 확인합니다. 같은 공고를 한 번 더 저장했을 때 새 페이지가 생기지 않고 기존 페이지가 업데이트되면 연결과 중복 방지가 모두 정상입니다.

## 오류 해결

| 표시되는 오류 | 확인할 항목 |
|---|---|
| 401 또는 토큰 오류 | 토큰 앞뒤 공백, 잘못된 워크스페이스 토큰, 폐기된 토큰 여부 |
| 403 또는 권한 오류 | 콘텐츠 읽기·삽입·업데이트 권한이 모두 켜져 있는지 |
| 404 또는 DB를 찾을 수 없음 | 데이터베이스에 연결을 추가했는지, 데이터 소스 ID를 입력했는지 |
| 속성 관련 오류 | 속성 이름과 Notion 유형이 표와 정확히 같은지 |
| 연결 이름이 검색되지 않음 | 연결과 데이터베이스가 같은 워크스페이스에 있는지 |

## 연결 해제

- 이 PC에서 토큰만 제거: 확장 프로그램의 **저장된 토큰 삭제** 사용
- 특정 데이터베이스 접근 제거: 데이터베이스 **••• → 연결**에서 연결 해제
- 연결 완전 폐기: Notion **설정 → 연결**에서 해당 내부 연결 삭제
